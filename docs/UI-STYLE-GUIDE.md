# LocalPM 视觉与 CSS 规范

当前基线：0.15.4。目标是接近 ChatGPT 的安静、克制、内容优先的观感，同时保持 API 工具的操作效率。本文件是后续 UI 修改的视觉依据；历史验收文档中的旧配色、字号和导航装饰以本文件为准。

## 1. 官方参考与取舍

| 参考                                                                                                  | 采用的原则                                                                 |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [Vercel Geist Typography](https://vercel.com/geist/typography)                                        | 主参考。按用途配套设置字号、行高与字重，区分常规文字、辅助标签和代码。     |
| [Vercel Geist Colors](https://vercel.com/geist/colors)                                                | 中性色承担背景、边框与主次文字；背景差异服务于层级，彩色承担有意义的反馈。 |
| [IBM Carbon Spacing](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/overview) | 补充间距刻度与变量的使用方法，不混入第二套视觉风格。                       |

下列数值是 LocalPM 的项目约定，不代表上述设计系统的原值。布局保留资源侧栏、请求标签、请求编辑、响应和 Console；完整请求页的整体比例优先于孤立控件的装饰。

## 2. 字体与排版

- UI 使用 `--font-ui`：系统界面字体，并显式提供苹方、微软雅黑、Noto 中文回退。应用不依赖在线字体；只在实际随包提供或加载字体时声明自定义字体。
- URL、参数值和代码使用 `--font-code`；CodeMirror 读取同一变量，字号继续由用户的编辑器设置控制。
- 常规字重 400，选中或操作文字 500，区域标题 600。通过用途区分层级；中文、英文、数字和图标一起校准基线。

| 用途                     | 字号 / 行高                       | 变量                                       |
| ------------------------ | --------------------------------- | ------------------------------------------ |
| 常规控件、导航、请求名称 | 14px / 20px                       | `--font-size-body`、`--line-ui`            |
| 工具栏、状态、耗时、说明 | 12px / 18px                       | `--font-size-meta`、`--line-meta`          |
| 小型 HTTP 方法标记       | 12px                              | `--font-size-badge`                        |
| 分组标题、设置页标题     | 16px                        | `--font-size-title`、`--font-size-heading` |
| 编辑器内容               | 默认 14px，行高 1.6；可调 12–20px | `--editor-font-size`、`--line-copy`        |

## 3. 间距与尺寸

| 用途                             | 约定                            |
| -------------------------------- | ------------------------------- |
| 图标与文字、紧邻控件             | 4px、8px                        |
| 控件内边距、同组间距             | 8px、12px                       |
| 请求与响应内容的水平起点         | 16px，URL、编辑区和响应内容对齐 |
| 分组与区域留白                   | 16px、24px、32px                |
| 常规控件 / URL 与发送按钮 / 顶栏 | 高 36px / 40px / 48px           |
| 紧凑工具按钮 / 常规图标          | 28px / 16px                     |
| 控件 / 浮层 / 对话框圆角         | 6px / 8px / 12px                |

使用 `--space-1/2/3/4/6/8`，对应 4/8/12/16/24/32px。先固定组件高度和文字行高，再安排内边距。边框、分隔线、拖动命中区、图标的光学校准和虚拟列表行高可以使用明确的几何值。虚拟列表的 36px 行高同时存在于渲染与滚动计算中，调整时一起修改。

## 4. 颜色与状态

- 浅色以白色内容区、浅灰侧栏为主；深色以中性深灰内容区、较深侧栏为主。常驻区域使用轻分隔线，阴影用于浮层。
- 资源导航与请求标签使用轻灰底；参数和响应内容切换使用文字、字重与细下划线，选中下划线复用 `--tab-indicator`。主操作使用黑白反色。HTTP 方法、错误、成功、未保存状态与代码高亮保留语义颜色；悬停、选中、键盘焦点和浮层遮罩分别使用现有语义变量。
- 键盘焦点与文本选区保持清晰的蓝色反馈。普通文字与辅助文字在实际背景上至少达到 4.5:1 对比度，弱化视觉权重依靠层级与留白。
- 辅助操作沿用悬停和键盘聚焦反馈；触控输入保留可发现入口。选中、悬停、焦点和未保存状态同时出现时仍须可辨认。

## 5. 结构与交互细节

极简通过降低装饰的权重实现；列边界、目录类型和键盘位置仍须一眼可辨。

| 场景          | 约定与取舍                                                                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JSON 括号配对 | 当前一对使用淡中性底色与清晰字色，2px 圆角、无外框；不改字重、内边距或字符宽度。未匹配括号用红色波浪下划线。配对与搜索、同词匹配使用独立颜色变量，避免修改一处波及其他状态。                      |
| 可编辑参数表  | Params、Headers、URL 编码表单和变量表共用浅色横竖分隔线；标题与输入列边界对齐，单元格无间隙。启用框整格可点击，停用值用辅助字色表示，保留编辑能力。只读列表按内容需要使用轻横线，不统一加满网格。 |
| 勾选框与焦点  | 鼠标勾选、取消后不叠加焦点外框；通过 `:focus-visible` 为键盘操作保留清晰的焦点环。原生勾选状态和鼠标/键盘焦点分别处理。                                                                           |
| 请求标签      | 按内容决定宽度，长名称省略；名称尾部到关闭按钮的间距由 4px 内边距控制，关闭区域保持 28px。保留关闭位置，悬停与未保存状态切换时文字不跳动。                                                        |
| 侧栏边界      | 导航、创建工具与资源列表之间使用 1px 轻分隔线。资源行通过缩进、选中和悬停区分，不逐行加线。                                                                                                       |
| 目录识别      | 子目录使用与现有图标一致的 16px、1.6px 描边文件夹图标；集合保留文字层级，请求保留 HTTP 方法。折叠箭头只表示展开状态，文件夹图标只表示资源类型。                                                   |
| 用法说明      | 可重复查阅的静态说明放在相邻问号入口；悬停、键盘聚焦和点击均可查看，Escape 关闭。浮层可悬停，受窗口边界约束，并避开编辑区域的裁剪。错误、运行结果和当前继承来源直接显示。                         |

说明浮层的交互参考 [WAI-ARIA Tooltip Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) 与 [WCAG 1.4.13](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)。以上视觉数值仍为 LocalPM 的项目取舍。

- 响应区主行保留状态、耗时和大小，数字直接显示最终值；环境放在主行并允许省略，完整环境名、接收时间和实际发送地址通过相邻详情入口查看，内容来自该次响应快照。重新发送期间与失败后保留的旧结果，显示有文字的“上次响应”标记。
- form-data 复用参数表的行高、列边界、整格启用框和键盘焦点；文件名单行省略，完整路径可悬停查看。末尾空行仅作输入入口，不自动写入请求。
- 请求头生成规则等静态说明使用问号入口；脚本运行失败或断言失败时自动展开结果，成功后恢复折叠，不把错误藏进帮助说明。

- 未保存的视觉标记集中在请求 Tab。配置页中的勾号仅表示已配置，与 Params/Headers 的数量标记一起说明配置状态。保存状态继续向辅助技术播报；保存中和保存失败直接显示，失败在小窗口也可见。
- 编辑器常用操作使用现有图标体系，提供本地化的 accessible name、悬停说明与快捷键；折叠等低频操作保留在更多菜单。编辑器使用直角、单条上分隔线，聚焦时改变该线颜色，内部工具栏不再叠加一圈边框。
- 同层请求的 HTTP 方法占固定列宽，长自定义方法省略并可悬停查看。请求名称优先分配宽度，路径保留开头与末级，完整路径和环境名可悬停查看。
- 普通通知 4 秒后消失，悬停或键盘聚焦时暂停，离开后重新计时；提供显式关闭按钮。操作失败不参与此计时，保留处理入口。
- UI 只使用 12、14、16px 三档文字尺寸，通过字重、颜色和留白建立层级。编辑器字号继续由用户独立控制。

## 6. CSS 维护

`src/styles/tokens.css` 集中维护字体、间距、尺寸、圆角与主题颜色；`src/style.css` 负责组件布局与状态；`editorTheme.ts` 复用相同字体和主题变量。

修改已有组件时，在其现有规则中更新。同一作用域的同名选择器集中定义；响应式与输入方式的覆盖集中在文件末尾。新增尺寸先匹配既有变量；确需例外时解释对应的排版或交互理由。

## 7. 验收

1. 使用同一组真实结构的请求数据比较改前、改后整页截图：中英混排、长名称、多个标签，以及 JSON 请求与响应。
2. 至少检查 900×640、1440×900，中英文与浅深主题。检查文字清晰度、基线、分组疏密、截断、按钮对齐和横向溢出。
3. 回归发送、显式保存、标签切换、编辑器字号、搜索、折叠、侧栏与 Console 拖动、键盘焦点及文本选区。
4. 运行 lint、typecheck、单元测试、版本一致性检查、生产构建及相关 Playwright 测试。`tests/visual-style.spec.ts` 检查窗口边界、URL 与发送按钮对齐、正文与辅助文字对比度，并生成 `artifacts/style-review/` 截图供人工复核。
5. 检查鼠标与键盘勾选的焦点差异、参数与密钥列对齐、短名与长名标签、目录折叠/拖动、问号的悬停/点击/键盘/Escape，以及括号配对、文本选择和搜索同时出现的效果。使用同一数据与窗口保存整页和关键区域截图。

浏览器截图使用测试后端，只证明布局与交互。Windows WebView2、macOS WKWebView 的实际字体渲染与安装包验收仍需在对应原生平台执行。
